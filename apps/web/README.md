# @visualinux/web

The frontend application implementing every screen in the UI/UX Screen Design document,
built from the components specified in the Component Hierarchy document.

**Status:** Milestone 0 — build tooling only (Vite + React + TypeScript configured and
verified working). No real screens yet. `LandingPage`, `AppShell`, `RouteGuard`, and the
authenticated routes begin in Milestone 1.

## Run locally
```
npm install
npm run dev --workspace=@visualinux/web
```
