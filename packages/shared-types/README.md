# @visualinux/shared-types

Type definitions shared between `apps/web` and `apps/api`. Populated incrementally:
Auth/User DTOs (Milestone 1), the command schema and animation event schema —
most important for the optimistic client-side simulation / server-authoritative
reconciliation pattern (Architecture §3) — (Milestone 2-3).

**Status:** Milestone 1 — Auth and User DTOs, matching API Design §1-2.
